
# SWYNEX – Biological Dataset Selection

## Internship Task
Task 1: Biological Dataset Selection

## Project Overview
This project documents the selection of a publicly available biological dataset related to breast cancer gene expression.

## Dataset Details
- Dataset ID: GSE139038
- Organism: Homo sapiens
- Experiment: Expression profiling by array
- Total samples: 65
- Repository: NCBI Gene Expression Omnibus (GEO)

## Research Question
What differences in gene expression can be observed between breast tumour tissues and normal breast tissues?

## Dataset Source
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE139038

## Report
The detailed dataset selection report is available in the PDF uploaded to this repository.

This task helped me understand how to identify, explore, and document publicly available biological datasets for research.
